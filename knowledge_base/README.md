# Knowledge base: Papyrus Bank (fictional)

Policy documents for a **fictional** digital bank, written for this project, in English (`en/`) and
Modern Standard Arabic (`ar/`). Every fee, limit and rule here is invented for the demo; nothing
describes a real bank.

- Each document has front matter (`doc_id`, `title`, `lang`) and numbered sections (`## 5. ...`).
- Section numbers are identical in both languages, so `cards#5` is the same section in English and Arabic.
- `intent_coverage.csv` maps each of the 77 Banking77 intents to the section(s) that answer it;
  it is used to evaluate retrieval.
